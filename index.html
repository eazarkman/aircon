aircon

aircon is a personal command-line tool that turns the owner's own Google Nest thermostat's air conditioning on and off using the Google Smart Device Management API.

Commands

aircon onTurn on cooling at the thermostat's current setpoint
aircon on 72Turn on cooling and set the target to 72°F (50–90°F; turns Eco off if needed)
aircon offTurn the thermostat off
aircon statusShow mode, Eco, HVAC activity, indoor temperature and setpoint

It is a private, single-user tool and is not offered to the public.
