aircon privacy policy

Last updated: October 7, 2026

aircon is a personal command-line tool used only by its owner to control their own Google Nest thermostat.

Data accessed

With the user's permission, aircon uses the Google Smart Device Management API (scope https://www.googleapis.com/auth/sdm.service) to read thermostat status (mode, temperature, setpoint, HVAC activity) and to change the thermostat mode.

Storage

OAuth credentials and tokens are stored only on the user's own computer, in a file readable only by that user. No data is sent to, stored on, or shared with any server other than Google's APIs.

Sharing

aircon does not sell, share, or transfer any user data to third parties, and does not use it for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or in the Google Home / Nest app, and by deleting the local configuration file.
